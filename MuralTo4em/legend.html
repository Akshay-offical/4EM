Mural sticky note palette for 4EM

Every 4EM class is represented by one combination of sticky note colour and shape. Build the legend board in Mural from this page: create one sticky per entry, set its colour to the hex value shown and its shape to rectangle or circle, and label it with the class name. During a modelling session, duplicate stickies from the legend board instead of choosing colours by hand.

The colours are shown here without the trailing alpha channel that Mural reports in its API export. The converter matches on the full eight-digit value, so a visually similar but different shade is not recognised. Generated from COLOR_SHAPE_TO_CLASS in mural_to_4em.py.
